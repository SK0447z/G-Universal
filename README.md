# G-Universal

G-Universal is a lightweight, low-overhead hardware control utility for Windows laptops. It provides direct hardware control for performance profiles, CPU boost modes, display refresh rates, keyboard lighting, battery health limits, and telemetry polling without requiring background OEM services or telemetry packages.

## Architecture

The project is structured around an extensible hardware abstraction layer centered on `ILaptopProvider`:

- `Providers/`: Contains brand-specific implementations that interact directly with low-level kernel drivers (`\\.\ATKACPI` via IOCTL) and vendor ACPI/WMI namespaces (`root\WMI` and `root\CIMV2`). An auto-detection factory instantiates the matching provider using motherboard identification.
- `Services/`: Universal platform helpers covering Windows power scheme modification via `powercfg.exe` (`PowerHelper`), display resolution/refresh rate management via Win32 display APIs (`DisplayHelper`), global keyboard hook and WMI event listeners (`HotkeyManager`), gamma ramp display dimming (`GammaRampHelper`), Windows Task Scheduler startup registration (`StartupHelper`), and diagnostic scanning (`HardwareScanner`).
- `UI/` and `UI/Controls/`: Utilitarian, fast Win32 Forms interface with custom double-buffered dark controls, on-screen notifications (`OsdWindow`), and a lightweight transparent metrics overlay (`MetricsOverlayWindow`).
- `Config/`: Minimal JSON-backed configuration (`AppSettings`).

### Protocol References and Credits

Protocol reverse-engineering and register implementations reference the following open-source projects:

- [seerge/g-helper](https://github.com/seerge/g-helper) for ASUS ATKACPI device endpoints, TUF RGB payload structure, and fan telemetry math.
- [LenovoLegionToolkit](https://github.com/BartoszCichecki/LenovoLegionToolkit) for Lenovo GameZone WMI methods and ITE HID RGB communication.
- [OmenMon](https://github.com/alou-S/OmenMon) for HP Omen/Victus BIOS mailbox interface specifications.
- [alienware-wmi](https://github.com/alien-m18/alienware-wmi) and community WMI dumps for Dell Alienware/G-Series thermal control.

## Security and Privilege Model

G-Universal requires Administrator privileges solely to issue kernel IOCTL commands to motherboard drivers and query root\WMI hardware nodes.

- User-configured custom application shortcuts strictly launch through Windows Explorer (`explorer.exe`) at standard user privileges. Raw shell string execution is disabled to prevent privilege escalation.
- Diagnostic hardware reports generated by `HardwareScanner` automatically redact personal hardware serial numbers, MAC addresses, and UUIDs.
- External system tool execution (`schtasks.exe`, `powercfg.exe`, `sc.exe`, `pnputil.exe`, `nvidia-smi.exe`) uses structured argument lists with `UseShellExecute = false` and `CreateNoWindow = true` to prevent command injection.

## Building from Source

### Prerequisites

- Windows 10 (version 1809 or higher) or Windows 11 (64-bit)
- .NET 8.0 SDK

### Build Commands

```bash
git clone https://github.com/SK0447z/G-Universal.git
cd G-Universal
dotnet build -c Release
```

The output executable will be placed in `bin/Release/net8.0-windows/win-x64/` (or single-file publish directory).
